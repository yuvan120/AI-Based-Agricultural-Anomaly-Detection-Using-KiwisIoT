An intelligent IoT platform using KiwisIoT and AI to detect agricultural threats, crop stress, and environmental anomalies.
#  📌 About the Project

AI-Based Agricultural Anomaly Detection Using KiwisIoT is an IoT-based smart agriculture project designed to monitor agricultural environmental conditions and identify unusual changes in sensor datAI-Based Agricultural Anomaly Detection Using KiwisIoT

## a.

Using the ESP32 microcontroller and connected sensors, the system collects real-time agricultural data such as soil moisture, temperature, humidity, and other environmental parameters.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can visualize and monitor the data through an online dashboard.

By analyzing sensor readings, the system can help identify abnormal conditions such as unusually high temperatures, low soil moisture, and unexpected environmental changes. AI-based analysis can further support anomaly identification and early detection of potential agricultural problems.

This project demonstrates how IoT and Artificial Intelligence can work together to support smart farming, improve agricultural monitoring, and enable data-driven farming decisions.
